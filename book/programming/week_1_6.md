At this point you are used to the fact that bugs in your code are a fact of life, but probably don't have a methodical way of dealing with them. Perhaps sometimes you get errors and have no idea how to fix them. This week we will consider various _error types_ and promote a structured approach to debugging by learning about the _traceback_ feature in Python.

This week we introduce several tools that, while simple, form foundational elements of the broader field of _software testing._ If you ever use or write more complex software (i.e., a collection of Python functions, modules, or a package), these tools are essential for any project.
